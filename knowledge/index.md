# Knowledge index — {{PROJECT_NAME}}

Entry point to what is known. **Observed facts only** — designs and decisions live in
`../artifacts/`. Blocks marked `AUTO` are regenerated by `tools/kb/refresh.py`; edit only
the prose outside them.

## How to find things (cheapest first)

1. **Graph** — everything known about an object, in one call:
   `uv run python tools/kb/graph.py about <OBJECT>`
2. **Catalog / sections** — which note, which lines:
   `uv run python tools/ingest/query.py "SELECT path, line_start, line_end FROM kb.sections WHERE heading ILIKE '%<topic>%'"`
3. **Structured SQL** — anything countable (`tools/ingest/query.py`).
4. **grep**, then `Read` with `offset`/`limit` on the section — never a whole large note.

`extracted/` holds machine extractions of `source/` (body immutable); `curated/` holds
syntheses we wrote. Both are citable at their `evidence` level; an extraction with
`status: extracted` is cited with "(extraction unchecked)".
