Sensitive documents

Sensitive data, AI under control.

Built into the system

  • Originals stay local and are never versioned
  • Only derived documentation is shared
  • Guards stop any edit to the sources
  • Mail participants de-identified on import
  • Every change traceable, by whom and when
  • No source content sent to external services

Agreed at project start

  • Data-owner approval to process the documents with AI
  • Only AI tools approved by the data owner
  • Where the repository lives and who can access it
  • A sensitivity class for every document at triage

Data minimisation by design: the model sees only the lines a question needs, never the whole archive.
